# 0043. 연결 승인 수명주기 — 버전 선언 전 게임 데이터 유보

- **상태**: 승인됨
- **날짜**: 2026-10-20
- **결정자**: 사용자 승인 방향(부모 확정 설계) · worker 구현

## 배경 (Context)

ADR-0028은 버전 **불일치** 클라이언트를 거부했지만 "선언 자체를 안 함" 경로가 맹점이었다(상용 점검 CON-001). `AttachConnection`의 큐 람다가 버전 확인 없이 Welcome→소유권 배정→캐치업→접속 이벤트를 무조건 실행했고, 복제 틱·스폰 브로드캐스트·캐치업·게임 ServerRpc 디스패치에도 승인 게이트가 없었다. 즉 프로토콜을 검증받지 않은 연결이 전체 게임 상태를 수신하고 RPC를 실행할 수 있었다.

## 결정 (Decision)

1. **`ServerConnection.VersionApproved` 승인 상태** — `ExpectedProtocolVersion`가 빈 문자열(비활성)이면 `AttachConnection`에서 즉시 동기 승인(현행 동작 완전 호환). 활성이면 와이어 7 선언이 수용될 때까지 미승인.
2. **승인 전 보류** — 소유권 재배정(후보·수신 모두 미승인 제외)·캐치업·`ClientConnected` 이벤트·복제 틱 송신·스폰 브로드캐스트·파괴 통보·LoadScene 브로드캐스트·씬 준비 게이트에서 미승인 연결 제외. Welcome은 항상 전송(클라가 선언에 필요한 서버 버전·세션 토큰 전달). 시스템 와이어 7/8/10/12는 게이트 밖 — 핸드셰이크 생존 필수. 미승인 연결 해제 시 `ClientDisconnected`·유예 세션 저장 생략(게임에 노출된 적 없음).
3. **승인 시 보류 해제** — `OnClientVersionDeclared` 수용 경로가 플래그를 세우고 `QueueOnMain`으로 보류 작업(대기 씬 참여→재배정→캐치업→`ClientConnected`)을 기존 순서대로 실행. `RunPostApproval`의 연결별 1회 플래그로 어떤 큐 순서에도 멱등(선언이 펌프보다 먼저 도착해도 이중 실행 없음). 재선언은 수용 후 무연산. 불일치는 기존 VersionMismatch 킥 유지.
4. **생성 허브 게임 ServerRpc 게이트** — 생성 디스패치가 `IsVersionApproved(UniNetConnId)` 검사 후 `ReportUnapprovedServerRpc`로 조용 기각(전역 카운터 `UnapprovedServerRpcDrops`가 유일 관측). 레이트리밋 검사 앞에 배치(미승인 홍수가 레이트 창을 소진하지 않음). 제너레이터 0.2.9.
5. **미선언 타임아웃** — `UniNetEndpointOptions.VersionDeclareTimeoutMs`(기본 10000, 0=스윕 비활성 — 보류는 유지)·`NetworkServer.VersionDeclareTimeoutMs`로 전달, 드라이버 틱에서 `SweepGraceSessions`와 동일 캐던스로 `SweepUnapprovedConnections` 실행 → 기존 킥 경로(VersionMismatch 공지→폐쇄) 재사용.

## 결과 (Consequences)

- **긍정**:
  - 미검증 연결의 게임 상태 노출·RPC 실행이 원천 차단(신뢰 경계를 Welcome 뒤에서 선언 수용 뒤로 이동).
  - 실제 클라이언트(생성 허브 자동 선언)는 무변경 — 승인이 수 밀리초 내 자동 완료.
  - 검사 비활성(빈 기대 버전) 경로는 기존과 완전 동일.
- **부담 / 리스크**:
  - 커스텀 채널/테스트 더블은 이제 선언(`OnClientVersionDeclared`)을 모델링해야 게임 데이터를 받는다(기존 EditMode 100개 attach 지점에 실제 클라와 동일한 선언 호출 추가 — 계약 정합화).
  - 미승인 연결이 타임아웃 0으로 무기한 보류 가능(게이트는 유지되므로 무해하나 연결 슬롯 점유 — `MaxConnections`로 상한).
  - 킥 경로 특성상 `DetachConnection` 전까지 스윕이 공지를 반복할 수 있다(공지는 멱등, 폐쇄는 최초 1회 시도).
- **폐기 방법**: `ExpectedProtocolVersion = ""` 설정 또는 각 필터의 `VersionApproved` 조건 제거·`RunPostApproval`을 원래 람다로 복원하면 기존 동작으로 돌아간다. 제너레이터는 0.2.8로 되돌린다.
