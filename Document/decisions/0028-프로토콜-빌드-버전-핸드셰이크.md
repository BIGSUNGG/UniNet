# 0028. 프로토콜/빌드 버전 핸드셰이크

- **상태**: 승인됨
- **날짜**: 2026-10-12
- **결정자**: /list 항목 3 (프로토콜/빌드 버전 핸드셰이크)

## 배경 (Context)

실운영 배포 주기에서 서버 업데이트와 클라이언트 업데이트 타이밍은 어긋난다. `Replicated` 필드 구조 변경·스폰 프리패베이크 차이가 있는 구버전 클라가 접속하면 동작이 미정의가 된다 (실사용 갭 검토 2026-10-12 높음 ⑥). Welcome에 버전 필드가 없었고, 강제 업데이트 플로우조차 게임이 첫 RPC로 자체 검증해야 했다.

제약: 상류(DRPC/Communication) 수정 불가 (ADR-0021). 연결 키는 사전공유 인증 용도로 버전 오버로딩은 부적절. 킥·종료 사유 인프라(ADR-0027)가 방금 구축됐다.

## 결정 (Decision)

1. **버전 선언-비교 모델** — 클라이언트는 접속 직후 생성 허브가 자동으로 로컬 버전을 선언한다(와이어 시스템 메시지 7, `UniNetEnvironment.LocalProtocolVersion`). 서버는 `NetworkServer.ExpectedProtocolVersion`과 비교해 불일치 시 `DisconnectClient(connId, VersionMismatch)`로 거부한다(생성 허브 경고 로그). **거부 사유가 클라에 전달되므로** 게임은 "업데이트 필요" UX로 즉시 분기할 수 있다.
2. **Welcome에 서버 버전 필드** — `SendWelcome(connId, serverVersion)`로 서버 버전도 전달된다. 클라는 `NetworkClient.ServerProtocolVersion`으로 열람 가능(참고용 — 권위 검사는 서버 측).
3. **설정** — `UniNetEndpointOptions.ProtocolVersion` (기본값 = 패키지 버전 `UniNetInfo.Version`). 같은 패키지끼리는 항상 일치하므로 기본 동작은 무관하게 연결되고, 게임은 빌드 버전을 지정해 강제 업데이트를 켠다. 서버에서 빈 문자열 지정 시 검사 비활성.
4. `UniNetDisconnectReason.VersionMismatch = 5` 추가 (ADR-0027 확장). 제너레이터 0.2.3.

거부 시점 계약: 버전 선언은 접속 직후 전송되지만 Welcome·캐치업과 경합하므로, 거부는 부착 직후 수 초 내 발생한다 (게임은 `ClientConnected` 직후 `ClientDisconnected(VersionMismatch)`를 핸드셰이크 실패로 취급). 부착 순서 근거 — DRPC의 accept 콜밭이 부착(AttachConnection)을 동기 실행하고 선언은 클라 연결 완료(≥1 RTT) 후에만 도착할 수 있어 실질 경합 불가; 이론적 미부착 창에서는 킥이 대상을 못 찾은 것이 `LogFault`로 노출된다(조용한 생존 없음).

## 결과 (Consequences)

- **긍정**: 상용 배포 필수 강제 업데이트 플로우의 프레임워크 기반. 기본값(패키지 버전)은 소비자 노력 0. Arena가 `ArenaConfig.ProtocolVersion`("arena-1")으로 사용 예시.
- **부담 / 리스크**: 선언-비교 경합 창(위 계약 문서화). 버전 문자열 비교는 정확 일치만 — 시맨틱 버전 규칙(호환 범위)이 필요해지면 별도 비교기 확장. **레거시 게이트 우회 맹점**: 와이어 7로 선언하는 것은 제너레이터 0.2.3+ 빌드뿐이다 — 0.2.2 이전으로 빌드된 기존 클라는 선언 자체를 안 보내므로 `ProtocolVersion`을 설정해도 거부되지 않는다(게이트는 0.2.3+ 세대부터 유효). 서버先 첫 롤아웃에서 배제해야 할 레거시 구버전이 정확히 이 세대다 — 필요하면 선언 데드라인(접속 후 N초 무선언 킥)을 확장 포인트로 추가한다. 구버전 서버(≤0.2.2)의 Welcome에는 버전 필드가 없어 신규 클라의 Welcome 핸들러는 격리된 예외 로그 후 세션을 유지한다(버전 null).
- **폐기 방법**: 상류가 연결 핸드셰이크 단계에서 버전 교환을 지원하면 선언 메시지를 대체한다.
