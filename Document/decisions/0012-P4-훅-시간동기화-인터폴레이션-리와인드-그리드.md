# 0012. P4 훅 — 시간 동기화·인터폴레이션 버퍼·리와인드(래그 컴펜세이션)·그리드 가시성

- **상태**: 승인됨
- **날짜**: 2026-09-20
- **결정자**: DS + pi

## 배경 (Context)

- P4 로드맵(예측·래그컴펜세이션·RepGraph·틱 스케줄링) 중 **UniNet 저장소만 수정해서 구현 가능한 항목**을 구현한다 (사용자 결정 — 기반 스택 불변 원칙).
- **사용자 결정 — 범위 확정**: 커스텀 NetSerialize·FastArray는 MP 수정이 필요하므로 **무조건 제외**(roadmap 표기 유지). 예측·래그컴펜세이션·RepGraph·틱 스케줄링은 구현.
- **사용자 결정 — 예시 수준**: Sandbox 아레나 게임플레이를 P4 방식으로 **실제 전환**한다 (기존 테스트도 갱신) — 클라 이동 예측, 히트스캔+래그컴펜세이션 발사.
- 참조: UE 5.7 (ReplicatedWorldTimeSeconds, 클라 보간 버퍼, FLagCompensation 위치 히스토리, RepGraph 그리드).

## 결정 (Decision)

1. **UniNetTime — 서버 권위 단조 시계** (`UniNet.Core.Hosting`):
   - 서버·호스트: 로컬 시계(`Time.unscaledTimeAsDouble`)가 곧 권위 시간. 순수 클라: TimeSync 수신으로 계산한 오프셋(EMA α=0.25)을 더한다. 드라이버가 1초 주기로 `SendTimeSync`를 전 연결에 브로드캐스트한다.
   - **와이어**: 시스템 메시지 methodId **5** = `[serverTime: double]` — `IUniNetSystemChannel.SendTimeSync` + 생성 클라 허브 수신 핸들. 수신은 네트워크 스레드이므로 적용을 메인 큐로 우회한다(Unity 시계는 메인 전용 — Spawn 핸들과 동일 패턴).
   - **서버·호스트는 ApplyServerTime을 무시한다** — 오프셋이 들어가면 기록 시계(원본)와 질의 시계(보정)가 어긋나 최신 샘플 질의가 미래 시각이 되는 결함 발생(구현 중 발견, PlayMode로 재현·검증).
   - **단조 보장**: `Now`가 역행하지 않게 마지막 값을 클램프 — TimeSync 평활로 인한 시간 역행이 인터폴레이션·리와인드 질의를 망가뜨리지 않게 한다.
2. **인터폴레이션 버퍼 — `SnapshotBuffer<T>`** (코어): 수신 스냅샷을 시간축에 적재하고 과거 시점(renderTime = Now − InterpolationDelay)으로 보간 질의. 시간 역전 스냅샷 폐기, 범위 밖 끝 값 홀드. 리모트 오브젝트의 "적용 시점"을 게임이 제어하는 틱 스케줄링 훅의 클라 측 상응물.
3. **위치 히스토리·리와인드 — `PositionHistory` + `NetworkBehaviour` 훅**:
   - `NetworkRewindHistory = true` (옵트인)인 오브젝트를 드라이버 서버 틱이 매 프레임 기록한다(링 버퍼 128 샘플 ≈ 2초).
   - 질의: `GetHistoryPosition(serverTime, out pos)` — 인접 샘플 선형 보간, 범위 밖 끝 값 홀드, 미기록 오브젝트는 현재 위치 반환.
   - **신뢰 경계**: hitTime은 서버가 `[Now − RewindWindow(1초), Now]`로 클램프 — 과도한 과거/미래 리와인드 거부.
4. **그리드 공간 분할 가시성 (RepGraph 스타일)**: `SetVisibilityGrid(cellSize, visibleRadius)` — 월드를 XZ 격자로 나눠 뷰어 반경 내 셀의 오브젝트만 관련으로 판정(양자화, 경계 오차 cellSize 이하). P3 계약 유지: 관련성 훅 AND, 뷰어 미설정 연결 페일오픈, 재진입 기준선 복구. 오브젝트별 NetworkCullDistance>0는 그리드와 AND. 위치 없는 오브젝트는 항상 관련.
5. **아레나 전환 (사용 예시)**:
   - **이동**: 이동 규칙을 `ArenaMovement.Step` 단일 공급원으로 추출 — 서버 권위 시뮬레이션과 클라 예측이 동일 규칙 공유. 소유 클라는 입력을 로컬 즉시 적용(예측)하고, 서버 상태 수신 시 축 단위 `ReconcileAxis`(스냅/소프트 조정). 리모트는 인터폴레이션 버퍼로 InterpolationDelay 뒤 시점 렌더.
   - **발사**: 투사체(총알)를 **히트스캔**으로 전환 — 발신자가 조준 시각(UniNetTime.Now)을 ServerRpc로 전달, 서버가 대상을 리와인드해 선분-원 판정. CritEvery 치명타·킬 플로우 유지.
   - ponytail: 입력 시퀀스 ack·미적용 입력 재적용 큐는 UE급 구현 — 예측 오차가 눈에 띄면 도입.
6. **ADR-0009/0011 계약 승계**: OwnerOnly 소유자 부재 유실, 비관련 전환 시 상태 고착(전파 파괴 미지원), 뷰어 위치 명시 주입 — 모두 유지.

## 결과 (Consequences)

- **긍정**: UE 패리티의 상호작용 축(시간 동기화·보간·리와인드) 확보. 아레나가 "서버 권위 + 클라 예측 + 래그컴펜세이션" 구조의 실동작 참고 구현이 됨. 제너레이터는 시스템 메시지 1건만 추가(0.1.2).
- **부담 / 리스크**: 예측 조정은 스냅/소프트 단순형(입력 재적용 큐 없음) — 고지연·급격한 조정에서 눈에 띌 수 있음. TimeSync 오프셋은 한 방향 지연 포함(정밀 RTT 보정 없음). 씬 오브젝트 재등록 시 그리드/가시성 상태는 DestroyObject에서 정리됨.
- **폐기 방법**: 시간 서비스·훅 계약 변경 시 새 ADR로 대체.

## 검증 증거 (2026-09-20)

- **EditMode 45/45** — 기존 38종 회귀 없음 + P4 신규 7종: `P4CoreTests` 5(UniNetTime EMA·SnapshotBuffer 보간/홀드/역전 폐기·PositionHistory 보간/클램프/덮어쓰기)·`GridVisibilityTests` 2(반경 밖 컬+뷰어 이동 재진입, 뷰어 미설정 페일오픈)
- **PlayMode 10/10** — 기존 8종(아레나 히트스캔 전환 포함) + `P4HookPlayTests` 2(TimeSync 동기화, 리와인드 히스토리 질의)
- **아레나 전환** — ArenaMovement 단일 공급원, ArenaPlayer 예측·인터폴레이션·히트스캔, ArenaFx.Tracer, ArenaBullet 제거(동적 스폰/파괴 커버리지는 플레이어 스폰·파괴가 담당)

## 알려진 한계·후속 과제

- 예측 조정 단순형 — 입력 ack 기반 재적용 미구현
- TimeSync 오프셋 RTT 보정 없음(EMA만) — 클라 발신 시각 신뢰는 서버 클램프로 방어
- 커스텀 NetSerialize·FastArray — MP 소스 수정 필요(P4 잔여, roadmap 표기)
- 연기분 RelevantMask 부실(연기 지간 중 관련성 변화 미반영) — 후속 ADR 후보
