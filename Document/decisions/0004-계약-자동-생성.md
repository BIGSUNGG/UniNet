# 0004. MonoBehaviour RPC 계약 자동 생성

- **상태**: 승인됨
- **날짜**: 2026-09-13
- **결정자**: 사용자 (프로젝트 소유자)

## 배경 (Context)

- DRPC는 C# 인터페이스 계약(`[RemoteProcedure]` + 허브 구현) 기반이다. 게임 개발자에게 인터페이스 계약 작성은 부담이며, "사용은 간단하게" 원칙과 충돌한다.
- 오브젝트 대상 RPC에는 네트워크 ID 기반 오브젝트 라우팅 코드도 반복적으로 필요하다 ([[plan]] 난점 1).

## 결정 (Decision)

UniNet 자체 Roslyn 소스 제너레이터가 MonoBehaviour 파생 클래스의 RPC 속성 메서드를 컴파일 시 스캔해
DRPC 계약 인터페이스·허브 코드·오브젝트 라우팅 코드를 **자동 생성**한다.
수동 계약 작성은 고급 시나리오용 폴백으로 남긴다.

## 결과 (Consequences)

- **긍정**: 속성 선언만으로 RPC가 동작한다(원칙 직접 구현). 계약이 항상 코드와 일치한다(컴파일 타임 검증). AOT 안전(소스젠 기반).
- **부담/리스크**: 제너레이터 개발·유지 비용이 초기에 집중된다. MP·DRPC 제너레이터와 병렬로 도는 Unity 컴파일 파이프라인 검증이 필요하다(Phase 0 스파이크 1번).
- **완화**: 스파이크 선실행, 생성 코드 디버깅 지원(생성 파일 저장), 수동 폴백 유지.
- **폐기 방법**: 수동 계약 방식으로 회귀 시 이 ADR을 대체하고 [[plan]]·[[architecture]]·[[conventions]]를 갱신한다.
