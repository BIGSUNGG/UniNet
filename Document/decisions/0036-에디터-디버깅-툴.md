# 0036. 에디터 디버깅 툴

- **상태**: 승인됨
- **날짜**: 2026-10-12
- **결정자**: /list 항목 11 (에디터 디버깅 툴)

## 배경 (Context)
실사용 갭 검토 중간 ⑩: 네트워크 인스펙터·프로파일러가 없어 튜닝 효과·연결 상태·오브젝트 소유권을 눈으로 볼 수 없었다.

## 결정 (Decision)
`UniNetDebuggerWindow` (Window → UniNet → Network Debugger) — Unity EditorWindow로 Play Mode 세션 중 실시간 표시:
1. **연결 목록** — connId·RTT(클라 보고)·플레이어 오브젝트·씬 준비·레이트 드롭·세션 토큰
2. **트래픽 통계** — 송수신 KB/msgs(ADR-0029)·지연 큐·레이트 드롭
3. **등록 오브젝트** — netId·타입·소유자·동적 여부
4. **서버 설정** — 프로토콜 버전·레이트리밋·유예 시간·대기 씬
5. **클라 상태** — RTT·세션 토큰·서버 버전·해제 사유·트래픽

읽기 전용(변이 없음)·자동 리프레시. 기능 예시는 에디터 툴 자체로 갈음(Sandbox 불필요).

## 결과 (Consequences)
- **긍정**: 개발·디버깅 시 네트워크 상태 즉시 가시. ADR-0029 통계 API의 소비자.
- **부담 / 리스크**: Editor 전용 asmdef — 런타임 크기 무영향. 자동 리프레시 매 프레임 repaint (Editor 전용 성능 영향 무시 가능).
- **폐기 방법**: 메뉴에서 열지 않으면 무영향.
